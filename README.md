# marching-trumpet
Marching-optimized trumpet\
OVERVIEW\
Center of mass is moved closer to performer, to improve endurance while marching. Bore and bell profile are optimized for acoustic requirements of marching band. Tubing/slide lengths tuned exactly for performance at Lucas Oil Stadium at 16.5 degrees Celsius. Other optimization/changes with further iterations.\
FILE DESCRIPTIONS\
FullModel is the full assembly. It contains one sub-assembly ( ValvesSub ) and six parts ( Bell , Leadpipe , Mouthpiece , BottomCap x3 ) (three are duplicates)\
ValvesSub is a sub-assembly. It contains 2 sub-assemblies ( Valve1Sub , Valve3Sub ) and two parts  ( ValveCasing , Valve2 )\
Valve1Sub is a sub-assembly. It contains two parts ( Valve1End , Valve1Slide )\
Valve3Sub is a sub-assembly. It contains two parts ( Valve3End , Valve3Slide )\
All parts are named to convention with modern trumpet nomenclature\
PistonSample is not in the full assembly. It is a trial run for an upcoming version that will contain pistons.\
